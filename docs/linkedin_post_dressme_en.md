Full closet, yet "nothing to wear"? 👗 We also buy things we already own, and overpack every trip.

That's the problem we set out to solve with DressMe, an AI assistant that helps you make the most of the clothes you already have.

How it works 🧠
Several AI agents (LangGraph) work on your real wardrobe. The language model understands and explains, while code verifies and calculates, so it never suggests a piece you don't own.

• RAG grounds style advice in fashion books, with sources.
• Computer vision (YOLO and GPT-4o vision) catalogs clothes from a photo or camera.
• XGBoost ranks what's missing and flags redundant purchases.
• An OR-Tools solver builds the lightest suitable suitcase.

The result: better outfits, lighter luggage and smarter buying decisions. ♻️
