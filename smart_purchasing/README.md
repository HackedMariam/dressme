# DressMe — Smart Purchasing Shopper Agent

A dynamic, tool-orchestrated Shopper Agent powered by **Qwen3 (via local Ollama)**, Python deterministic algorithms, session checkpointing, and an interactive desktop popup interface.

---

## 🌟 Architecture & Responsibilities

### 🤖 What Qwen Decides (Agent Brain)
1. **Tool selection**: Determines which tools are relevant based on the user's inquiry.
2. **Information gathering**: Detects missing facts (e.g. unknown budget or occasion) and decides whether to pause and ask the user.
3. **Adaptive execution**: Responds to tool results (e.g. if the user already owns a similar blazer, investigates whether the candidate item offers unique outfit pairings).
4. **Completion check**: Verifies whether there is sufficient evidence to deliver a recommendation or if further investigation is needed.
5. **Contextual recommendation**: Interprets the calculated score in context, explicitly explaining trade-offs—such as when an item scores high in versatility but conflicts with the user's budget.

### 🐍 What Python Handles (Deterministic Foundation)
- Arithmetic calculations, strict weighting formula ($S$), constraint boundaries, and data validation.
- The LLM **never** invents the mathematical score or hallucinates owned clothing.

---

## 🛠️ The 5 Specialized Tools

| # | Tool Name | What It Does & What It Returns |
|---|---|---|
| **1** | **`analyze_item`** | Extracts dominant color hue (via PIL) and feature embedding vector from product image. |
| **2** | **`find_similar_items`** | Queries owned closet for duplicate pieces and calculates functional redundancy. |
| **3** | **`check_outfit_compatibility`** | Checks how many existing outfits the item pairs with. Returns: *"This item is compatible with X outfit(s) in your wardrobe (Average compatibility: Y%)"*. |
| **4** | **`analyze_wardrobe_gaps`** | Identifies wardrobe coverage priorities (essential gap, color diversity, or low-priority duplicate). |
| **5** | **`calculate_purchase_value`** | Deterministic score formula: <br>$$S = 0.30\cdot O + 0.20\cdot G + 0.20\cdot V + 0.15\cdot P + 0.15\cdot (100 - R) - \text{BudgetPenalty}$$ |

## 🖥️ How to Run

### 1. Autonomous Live Inference (CLI & Notebook — No Ollama Needed)
Runs on **any computer locally (GPU or CPU)** with zero API keys or secrets:

#### 📥 The 4 Inputs:
1. **`--image`**: Garment image (Web URL or local path). *Optional: defaults to `data/sample_camel_blazer.jpg` if omitted.*
2. **`--price`**: Candidate item price (e.g. `45.0`).
3. **`--budget`**: User's budget (e.g. `60.0`).
4. **`--prompt`**: Natural language question (e.g. `"Can I wear this to work?"`).

```bash
# Option A: From an Internet Image URL
python inference.py --image "https://images.unsplash.com/photo-1596755094514-f87e34085b2c?w=500" --price 45.0 --budget 60.0 --prompt "Can I wear this to a wedding?"

# Option B: From a Local Image File
python inference.py --image "data/sample_camel_blazer.jpg" --price 80.0 --budget 100.0 --prompt "Is this suitable for office meetings?"

# Option C: Quick Test with Default Fallback Image (no --image needed)
python inference.py --price 35.0 --budget 50.0 --prompt "Should I buy this for casual wear?"

# Option D: Instant Deterministic Test (Vision + XGBoost, skips Qwen load)
python inference.py --skip-llm
```
Or open **`dressme_agent_inference.ipynb`** locally, in Google Colab, or on Kaggle.

### 2. Interactive Desktop Popup App (Choose Image & Prompt)
Run the desktop GUI with image file browser and interactive dialogs:
```bash
python gui_run.py
```
- Click **"Browse Image..."** to select any photo from your computer.
- Enter your **Prompt**, **Price**, and optional **Budget**.
- If Budget is left blank, the agent dynamically detects the missing fact at Step 4 and opens an interactive popup prompt asking for your budget!
- Clearly labels whether output was generated by `[QWEN3-OLLAMA]` or `[FALLBACK]`.

### 2. Run Comprehensive Evaluation Metrics
Test all 4 benchmark dimensions (Information gathering, Known budget bypass, Budget conflict penalty, Redundancy detection):
```bash
python evaluate_metrics.py
```

### 3. Run Unit & Image Tests
```bash
python test_all.py
```

### 4. Run CLI Interactive Demo
```bash
python demo_shopper.py
```

### 5. Launch FastAPI Web Server
```bash
uvicorn main:app --reload --port 8000
```
- Interactive Swagger UI: [http://localhost:8000/docs](http://localhost:8000/docs)
- Evaluate Endpoint: `POST /api/v1/purchase/evaluate`
